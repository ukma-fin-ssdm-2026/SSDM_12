# Лаб 9 — індивідуальні відео

Кожен учасник додає власним комітом файл з одним посиланням на Loom-відео
тривалістю до 5 хвилин. Для відео увімкніть доступ **Anyone with the link**.

У відео покажіть одну особисто знайдену проблему, поясніть її наслідок,
покажіть виправлення або перевірку й додайте коротку рефлексію.
Кожен заявлений бонус має пояснити у відео щонайменше один учасник.
