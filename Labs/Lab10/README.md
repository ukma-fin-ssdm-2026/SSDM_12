# Лаб 10 — індивідуальні відео

Кожен учасник додає власним комітом файл з одним посиланням на Loom-відео тривалістю до
5 хвилин. Для відео увімкніть доступ **Anyone with the link**.

У відео за умовою Лаб 10 кожен показує:

1. власний внесок — які дані зібрав, яку метрику порахував, яку дію запропонував чи реалізував;
2. один червоний запуск на `main` і як команда повернула зелений;
3. одну–дві пропозиції, як покращити практики CI/CD команди.
