1"""Шаблон маршруту для журналу доступу. 

2 

3Журнал доступу пише шлях запиту. Конкретний шлях містить ідентифікатори 

4(`/api/v1/bookings/3fa85f64-…`), тож у лог потрапляють дані, яких там бути не має 

5(THR-09, CWE-532), і рядки неможливо згрупувати за маршрутом для PERF-001/PERF-002. 

6 

7Маскуємо лише канонічну форму UUID із дефісами: саме її віддає FastAPI для параметрів 

8типу `uuid.UUID`. Ширше правило помилково маскувало б людиночитані сегменти. 

9""" 

10 

11import uuid 

12 

13PLACEHOLDER = "{id}" 

14 

15 

16def _is_identifier(segment: str) -> bool: 

17 """Чи є сегмент UUID у канонічній формі з дефісами.""" 

18 try: 

19 return str(uuid.UUID(segment)) == segment.lower() 

20 except ValueError: 

21 return False 

22 

23 

24def route_template(path: str) -> str: 

25 """Повертає шлях, де сегменти-ідентифікатори замінено на `{id}`.""" 

26 return "/".join(PLACEHOLDER if _is_identifier(s) else s for s in path.split("/"))
