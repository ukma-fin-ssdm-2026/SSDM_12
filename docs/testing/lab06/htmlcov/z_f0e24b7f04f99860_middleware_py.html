1"""Наскрізна обробка запитів: ідентифікатор запиту, версія API, кешування, журнал. 

2 

3- `X-Request-ID`: приймаємо від клієнта, якщо він безпечного формату, інакше генеруємо. 

4 Той самий ідентифікатор потрапляє в тіло помилки (`request_id`) і в журнал — 

5 так звернення користувача знаходять у логах (Лекція 4, §3.2). 

6- `API-Version`: версія контракту у кожній відповіді (версіонування в коді). 

7- `Cache-Control: no-store` для `/api/`: відповіді містять персональні дані, а кешу 

8 немає, доки вимір PERF-001 не покаже потреби (DD-12). 

9- Журнал — один рядок JSON на запит: метод, шаблон маршруту, статус, тривалість, 

10 користувач. Ідентифікатори зі шляху замінено на `{id}` (THR-09, CWE-532). 

11 Тіла запитів, токени й рядок запиту не журналюються (THR-02, THR-09). 

12"""

35def install_middleware(app: FastAPI) -> None: 

36 """Підключає middleware до застосунку.""" 

37 

38 @app.middleware("http") 

39 async def request_context( 

40 request: Request, 

41 call_next: Callable[[Request], Awaitable[Response]], 

42 ) -> Response: 

43 request_id = _incoming_request_id(request) 

44 request.state.request_id = request_id 

45 started = time.perf_counter() 

46 response = await call_next(request) 

47 response.headers["X-Request-ID"] = request_id 

48 response.headers["API-Version"] = API_VERSION 

49 if request.url.path.startswith("/api/"): 

50 response.headers.setdefault("Cache-Control", "no-store") 

51 access_log.info( 

52 json.dumps( 

53 { 

54 "event": "request", 

55 "request_id": request_id, 

56 "method": request.method, 

57 "path": route_template(request.url.path), 

58 "status": response.status_code, 

59 "duration_ms": round((time.perf_counter() - started) * 1000, 1), 

60 "user_id": getattr(request.state, "user_id", None), 

61 }, 

62 ensure_ascii=False, 

63 ) 

64 ) 

65 return response
