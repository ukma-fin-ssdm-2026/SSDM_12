Cosmic Ray 8.7.0, усі стандартні оператори для `src/api/resource_rules.py`,
цільові unit-тести. Модуль має SHA-256 `ce89fccaede2c12d94f1033a4f96281463053e35e0a302683f94d31b28306c6b`.
Запуск у тимчасовій копії, робоче джерело не змінюється.

Це контрольне порівняння наборів тестів, не особиста RED/GREEN-історія:
`--label before` запускає наявний набір без `bool_capacity` і `strict_resource_type`,
`--label after` — усі тести файлу. У першому збереженому прогоні `strict_resource_type`
ще не було написано. Зафіксований `before` не слід переписувати без пояснення.

**Знахідка.** Мутант `if kind is ResourceType.ROOM` →
`if kind == ResourceType.ROOM` виживав: StrEnum дорівнює рядку `"room"`.
Тести перевіряли Enum і `"unknown"`, але не рядок із допустимим значенням.
Додано `test_strict_resource_type_requires_enum_not_raw_string`:
`("room",20)`, `("consultation",None)`, `("unknown",20)`, `("aaa",None)`.
Він убиває цей та інші три вцілілі мутанти порівняння (`is` → `==`, `<=`, `>=`).
Окрема регресія зберігає заборону bool як місткості.

[Початковий прогін](evidence/mutation-before.json) і [повний](evidence/mutation-after.json)
містять diff і вивід кожного мутанта. У фінальному прогоні 38 убитих, 0 уцілілих,
0 некомпетентних. 100% стосується лише цього малого модуля й набору операторів,
не всього проєкту й не відсутності всіх можливих дефектів.

Відтворення: установити `requirements-mutation.txt`, запустити
`python scripts/mutation_lab06.py --label after`. Cosmic Ray — додатковий локальний
інструмент, не уповільнює кожен звичайний PR CI. Пояснення бонусу — у відео Павла.
